# 🛒 E-Commerce Platform

Full Stack e-commerce platform developed with React and .NET, focused on providing a modern online shopping experience with secure authentication, order management, and payment validation.

---

# 📌 Description

This project is a full stack web application designed for selling clothing and home products through an intuitive and scalable platform.

The system was developed using React for the frontend and .NET for the backend, following modern web development practices and agile methodologies.

The platform includes features such as:

- Secure JWT authentication
- Shopping cart and order management
- Product catalog
- Manual SINPE Móvil payment validation
- SQL Server database deployed on Azure
- Automated end-to-end testing with Playwright

# 📊 System Workflow

1. Users browse products and add items to the shopping cart  
2. The system manages authentication using JWT tokens  
3. Orders are processed and validated by the backend  
4. Customers complete payments through SINPE Móvil  
5. Administrators manually verify payments  
6. Data is stored and managed in SQL Server hosted on Azure
